# Pulmonary Guidelines

This directory contains 30 pulmonary guidelines for top ER presentations, following the established format.

## Guidelines Included

### **EMERGENT** (Life-threatening)
1. **Acute Respiratory Distress Syndrome (ARDS)** - Rapid onset, bilateral infiltrates
2. **Anaphylaxis** - Multi-system allergic reaction
3. **Epiglottitis** - Upper airway obstruction
4. **Foreign Body Aspiration** - Airway obstruction
5. **Pulmonary Edema** - Heart failure with fluid in lungs
6. **Pulmonary Embolism** - Blood clot in lungs
7. **Respiratory Failure** - Inability to maintain oxygenation

### **URGENT** (Requires prompt attention)
8. **Acute Asthma Exacerbation** - Bronchospasm
9. **Aspiration Pneumonia** - Infection from aspirated material
10. **Chronic Obstructive Pulmonary Disease (COPD)** - Chronic lung disease
11. **Cystic Fibrosis** - Genetic lung disease
12. **Lung Abscess** - Localized lung infection
13. **Lung Cancer** - Malignant lung tumor
14. **Pleural Effusion** - Fluid around lungs
15. **Pneumonia** - Lung infection
16. **Pneumothorax** - Collapsed lung
17. **Pulmonary Fibrosis** - Lung scarring
18. **Pulmonary Hypertension** - High blood pressure in lungs
19. **Pulmonary Tuberculosis** - Bacterial lung infection
20. **Viral Pneumonia** - Viral lung infection

### **ROUTINE** (Can be managed outpatient)
21. **Acute Bronchitis** - Inflammation of airways
22. **Atelectasis** - Collapsed lung tissue
23. **Bronchiectasis** - Dilated airways
24. **Hyperventilation Syndrome** - Anxiety-related breathing
25. **Influenza** - Viral respiratory illness
26. **Sarcoidosis** - Inflammatory lung disease
27. **Sleep Apnea** - Breathing cessation during sleep
28. **Upper Respiratory Infection (URI)** - Common cold

## Format

Each guideline follows the established format with:
- **condition**: Medical condition name
- **icd10**: ICD-10 code
- **snomed**: SNOMED code
- **sex**: both/male/female
- **prevalence**: common/uncommon/rare
- **chief_complaint_triggers**: Common patient descriptions
- **urgency**: emergent/urgent/routine
- **key_features**: OLDCARTS-structured presentation
- **red_flags**: Critical warning signs

## Usage

These guidelines are designed to work with the adaptive diagnostic engine for pulmonary presentations in the emergency department.
