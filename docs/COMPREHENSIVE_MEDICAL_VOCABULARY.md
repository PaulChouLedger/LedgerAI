## 🔍 **Automatic Detection Patterns**

### **Medical Suffixes (Catches Thousands of Terms)**
- **-itis** → Inflammation (e.g., appendicitis, gastritis)
- **-osis** → Disease/condition (e.g., cirrhosis, psychosis)
- **-emia** → Blood condition (e.g., anemia, septicemia)
- **-pathy** → Disease (e.g., neuropathy, cardiomyopathy)
- **-trophy** → Growth/nutrition (e.g., dystrophy, atrophy)
- **-plasia** → Formation (e.g., dysplasia, hyperplasia)
- **-ectomy** → Surgical removal (e.g., appendectomy)
- **-otomy** → Incision (e.g., tracheotomy)
- **-scopy** → Visual examination (e.g., endoscopy)
- **-ology** → Study of (e.g., cardiology)
- **-ologist** → Specialist (e.g., neurologist)
- **-algia** → Pain (e.g., neuralgia, myalgia)
