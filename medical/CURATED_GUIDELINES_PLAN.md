# Curated Diagnostic Guidelines Plan

## Overview
Hand-curated, evidence-based diagnostic guidelines for common presentations.
Designed for RAG ingestion and LLM-powered dynamic diagnostic questioning.

## Upgrade Path
- **Current:** Curated guidelines (free, high-quality)
- **Future:** UpToDate API integration (when revenue allows)
